Research notes

- Primary technical sources only were used for normative behavior and version-sensitive claims.
- RWS 1.x and RWS 2.0 differ in protocol details, media types, authentication/session handling, and supported resources. Code in the companion project defaults to read-only and requires explicit opt-in for writes.
- RAPID Socket Messaging is a TCP byte stream. Application messages therefore require explicit framing; this package uses CRLF-terminated ASCII frames for the RAPID exercise and newline-delimited JSON for Python-native clients.
- Tailscale provides a secure access path. It is not treated as a robot safety function or deterministic real-time fieldbus.
- EGM is documented as a separate UDP/protobuf motion-guidance option and is not tunneled into the basic socket exercise.
