# ABB 로봇 타이어 제조 셀 자동화

대한상공회의소 천안기술교육센터 자동화 설비 과정 프로젝트입니다.
컨베이어·프레스·냉각·색상 판별·코팅·창고 적재를 ABB 로봇에서 통합 제어합니다.

## 핵심 파일

| 파일                                             | 설명                                                |
| ---------------------------------------------- | ------------------------------------------------- |
| `project.mod`                                  | 메인 RAPID 모듈. 공정 시퀀스, 좌표 티칭, TCP 서버, 비상정지 트랩       |
| `DI_DO_Signals.csv`                            | DI/DO 신호 정리표 (신호명·설명·코드 줄번호)                      |
| `CLAUDE.md`                                    | 공정 흐름, 코드 컨벤션, 미해결 이슈 정리                          |
| [../PLC\_ServerConnect/](../PLC_ServerConnect) | PC측 Python TCP 클라이언트 (`project.mod`의 `Main()`과 짝) |

## 공정 흐름

컨베이어1(di21) → 프레스(di22, 냉각 스윕) → 컨베이어2(di23, 색상 판별)

- 검정(정상, di04) → 컨베이어3 → 비드 코팅(di24) → 원형 스프레이(di25) → 창고 적재(di26)
- 흰색(불량, di05) → 트래시 분리 후 사이클 종료

창고 적재는 `Count`로 박스 4개에 순차 적재하고, 4개가 차면 일괄 이송 후 초기화합니다.

## 기타

`practice/` 는 수업 실습용 모듈, `RAPID_Server_Study/` 는 RAPID·서버 학습 자료,
`SETUP_LOG.md` 는 VSCode/RAPID 확장 세팅 로그입니다. 본 프로젝트와 별개입니다.
