# 콘솔 키오스크 구현

대한상공회의소 천안기술교육센터 프로젝트입니다.
관리자와 고객의 업무 흐름을 분리한 콘솔 키오스크로, 메뉴 변경부터 주문·할인·결제·
영수증 저장·매출 조회까지 JSON 기반의 일관된 데이터 흐름으로 통합했습니다.

## 사용 기술

C++, JSON

## 구성

| 파일                            | 역할                       |
| ----------------------------- | ------------------------ |
| `ProjectManager.cpp`          | 프로그램 진입점 및 화면 전환         |
| `DataManager.*`               | JSON 파일 입출력과 데이터 영속성     |
| `Display_selling.*`           | 고객 주문 화면                 |
| `Display_Manager.*`           | 관리자 화면 (메뉴·가격 변경, 매출 조회) |
| `Login.*`                     | 사용자·역할 기반 접근 권한 검사       |
| `Shpping.*`                   | 장바구니 (수량 누적, 부분 취소)      |
| `Payment.*`                   | 카드사 판별 및 현금 투입 결제 시뮬레이션  |
| `CartUtil.h`, `ConsoleUtil.*` | 장바구니 계산·콘솔 입출력 공통 모듈     |

## 주요 해결 과제

주문·관리·결제 모듈에서 입력 처리와 데이터 계산 로직이 중복되어 기능 확장이
어려웠습니다. `DataManager`, `ConsoleUtil`, `CartUtil` 을 공통 모듈로 분리하고
판매·관리 화면을 독립적인 흐름으로 재구성해, 동일한 JSON 구조 위에서 메뉴 변경·주문·
결제·매출 조회가 연결되고 재실행 후에도 데이터가 유지되도록 했습니다.
